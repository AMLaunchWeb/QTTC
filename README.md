# QTTC — Quality Technology Foundation for Transport

One-page bilingual website for Quality Technology Foundation for Transport (Dammam).

Photos and the QTTC logo are bundled in `src/assets/` so they load on any host.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Stack

Vite, React, TypeScript. English / Arabic toggle with RTL.

Draft by [AM Launch Web](https://amlaunchweb.com).
